HematRumah is an Indonesian household budget site that helps a family see where the month's money went and what is still safe to spend. It tracks monthly income against spending per category, lists transactions and recurring bills, follows savings goals, and works fully offline from its own static files on desktop and phone. A month switcher replays three months of real Rupiah figures, and an add-transaction form updates every total live.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
